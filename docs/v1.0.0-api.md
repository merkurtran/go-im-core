### 2.3 HTTP Handler 模板

```go
func (h *XxxHandler) DoSomething(c *gin.Context) {
    var req service.XxxRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        response.Error(c, http.StatusBadRequest, 1001, "invalid request")
        return
    }

    userID := c.GetString("user_id") // 从 JWT 上下文拿当前用户

    resp, err := h.svc.DoSomething(c.Request.Context(), &req)
    if err != nil {
        switch {
        case errors.Is(err, service.ErrXxx):
            response.Error(c, http.StatusNotFound, 2003, "xxx")
        default:
            response.Error(c, http.StatusInternalServerError, 5001, "server error")
        }
        return
    }
    response.Success(c, resp)
}
```

## 五、WebSocket 事件协议

### 客户端 → 服务端

| Event | Payload | 说明 |
|-------|---------|------|
| `message` | `{ receiver_id, content, message_type }` | 发送消息 |
| `ack` | `{ message_id, other_user_id, status }` | 确认已读，status=delivered/read |
| `ping` | `{}` | 心跳 |
| `typing` | `{ receiver_id }` | 正在输入 |
| `recall` | `{ message_id }` | 撤回消息 |

### 服务端 → 客户端

| Event | Payload | 说明 |
|-------|---------|------|
| `message` | `{ message_id, sender_id, receiver_id, content, msg_type, status, created_at }` | 收到新消息 |
| `ack` | `{ message_id, status }` | 发送回执（sent） |
| `delivered` | `{ message_id }` | 消息已送达（接收方在线时自动触发） |
| `read` | `{ other_user_id }` | 对方已读回执 |
| `unread` | `{ count }` | 未读数推送 |
| `pong` | `{}` | 心跳回复 |
| `status` | `{ user_id, status }` | 好友在线状态变更 |
| `typing` | `{ user_id }` | 对方正在输入 |
| `recalled` | `{ message_id, sender_id }` | 消息已被撤回 |
| `friend_request` | `{ from_user_id, from_nickname, from_avatar }` | 收到好友请求 |
| `friend_request_accepted` | `{ user_id, nickname, avatar }` | 好友请求已通过 |
