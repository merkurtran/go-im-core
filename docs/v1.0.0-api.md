## 接口文档 v1.0

### 基础信息

| 项 | 值 |
|--|--|
| 基础 URL | `http://localhost:8080/api/v1` |
| WebSocket | `ws://localhost:8080/ws` |
| 认证方式 | Bearer Token（JWT）|
| 内容类型 | `application/json` |

---

### 通用响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | int | 0=成功，非0=错误码 |
| `message` | string | 提示信息 |
| `data` | object/array | 业务数据，错误时可能为 null |

---

### 通用错误码

| 错误码 | 含义 | HTTP 状态码 |
|--------|------|-------------|
| 0 | 成功 | 200 |
| 1001 | 参数错误 | 400 |
| 1002 | 未授权 | 401 |
| 1003 | 禁止访问 | 403 |
| 1004 | 资源不存在 | 404 |
| 1005 | 资源冲突 | 409 |
| 2001 | 用户名已存在 | 409 |
| 2002 | 用户名或密码错误 | 401 |
| 2003 | Token 无效或过期 | 401 |
| 3001 | 消息发送失败 | 500 |
| 5001 | 服务器内部错误 | 500 |

## 认证模块

### 1. 用户注册

| | |
|--|--|
| **接口** | `POST /auth/register` |
| **描述** | 新用户注册 |
| **认证** | 不需要 |

**请求体：**
```json
{
  "username": "alice",
  "password": "SecurePass123!",
  "nickname": "Alice"
}
```

| 字段 | 类型 | 必填 | 约束 |
|------|------|------|------|
| `username` | string | 是 | 3-20位，字母数字下划线 |
| `password` | string | 是 | 8-32位，至少包含字母和数字 |
| `nickname` | string | 否 | 2-20位，默认同 username |

**成功响应（201）：**
```json
{
  "code": 0,
  "message": "注册成功",
  "data": {
    "user_id": "64a1b2c3d4e5f6a7b8c9d0e1",
    "username": "alice",
    "nickname": "Alice",
    "created_at": "2024-01-15T08:30:00Z"
  }
}
```

**错误响应：**
```json
// 用户名已存在（409）
{
  "code": 2001,
  "message": "用户名已被注册",
  "data": null
}
```

---

### 2. 用户登录

| | |
|--|--|
| **接口** | `POST /auth/login` |
| **描述** | 用户登录，获取 JWT |
| **认证** | 不需要 |

**请求体：**
```json
{
  "username": "alice",
  "password": "SecurePass123!"
}
```

**成功响应（200）：**
```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIs...",
    "expires_in": 86400,
    "user": {
      "user_id": "64a1b2c3d4e5f6a7b8c9d0e1",
      "username": "alice",
      "nickname": "Alice"
    }
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `access_token` | string | 访问令牌，有效期24小时 |
| `refresh_token` | string | 刷新令牌，有效期7天 |
| `expires_in` | int | access_token 有效秒数 |

**错误响应：**
```json
// 用户名或密码错误（401）
{
  "code": 2002,
  "message": "用户名或密码错误",
  "data": null
}
```

## 消息模块

### 5. 发送消息

| | |
|--|--|
| **接口** | `POST /messages` |
| **描述** | 发送消息（REST 方式，用于离线消息或补发）|
| **认证** | Bearer Token |

**请求体：**
```json
{
  "receiver_id": "64a1b2c3d4e5f6a7b8c9d0e2",
  "content": "你好，在吗？",
  "msg_type": "text"
}
```

| 字段 | 类型 | 必填 | 约束 |
|------|------|------|------|
| `receiver_id` | string | 是 | MongoDB ObjectID |
| `content` | string | 是 | 文本最大 4096 字符 |
| `msg_type` | string | 是 | `text`/`image`/`file` |

**成功响应（201）：**
```json
{
  "code": 0,
  "message": "发送成功",
  "data": {
    "message_id": "64a1b2c3d4e5f6a7b8c9d0f1",
    "sender_id": "64a1b2c3d4e5f6a7b8c9d0e1",
    "receiver_id": "64a1b2c3d4e5f6a7b8c9d0e2",
    "content": "你好，在吗？",
    "msg_type": "text",
    "status": "sent",
    "created_at": "2024-01-15T10:30:00Z"
  }
}
```

---

### 6. 获取消息列表

| | |
|--|--|
| **接口** | `GET /messages` |
| **描述** | 获取与某用户的消息记录 |
| **认证** | Bearer Token |

**查询参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `user_id` | string | 是 | 对方用户 ID |
| `limit` | int | 否 | 每页数量，默认 20，最大 100 |
| `offset` | int | 否 | 偏移量，默认 0 |
| `before_id` | string | 否 | 分页游标（可选）|

**请求示例：**
```
GET /messages?user_id=64a1b2c3d4e5f6a7b8c9d0e2&limit=20&offset=0
```

**成功响应（200）：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 156,
    "messages": [
      {
        "message_id": "64a1b2c3d4e5f6a7b8c9d0f1",
        "sender_id": "64a1b2c3d4e5f6a7b8c9d0e1",
        "receiver_id": "64a1b2c3d4e5f6a7b8c9d0e2",
        "content": "你好，在吗？",
        "msg_type": "text",
        "status": "read",
        "created_at": "2024-01-15T10:30:00Z"
      }
    ],
    "has_more": true
  }
}
```

## WebSocket 模块

### 连接建立

| | |
|--|--|
| **地址** | `ws://localhost:8080/ws` |
| **认证** | 通过 Query 参数传递 Token |
| **示例** | `ws://localhost:8080/ws?token=eyJhbGciOiJIUzI1NiIs...` |

### 消息格式（JSON）

```json
{
  "event": "message.send",
  "payload": {},
  "timestamp": "2024-01-15T10:30:00Z",
  "seq": 1
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `event` | string | 事件类型 |
| `payload` | object | 事件数据 |
| `timestamp` | string | ISO 8601 时间 |
| `seq` | int | 客户端序列号，用于确认 |

---

### 客户端 → 服务器 事件

#### 8. 发送实时消息

```json
{
  "event": "message.send",
  "payload": {
    "receiver_id": "64a1b2c3d4e5f6a7b8c9d0e2",
    "content": "你好，在吗？",
    "msg_type": "text"
  },
  "seq": 1
}
```

**服务器确认：**
```json
{
  "event": "message.ack",
  "payload": {
    "seq": 1,
    "message_id": "64a1b2c3d4e5f6a7b8c9d0f1",
    "status": "delivered"
  }
}
```

---

#### 9. 心跳

```json
{
  "event": "ping",
  "payload": {},
  "seq": 0
}
```

**服务器响应：**
```json
{
  "event": "pong",
  "payload": {
    "server_time": "2024-01-15T10:30:05Z"
  }
}
```

## 数据模型

### User

```go
type User struct {
    ID        string    `bson:"_id,omitempty" json:"user_id"`
    Username  string    `bson:"username" json:"username"`
    Password  string    `bson:"password" json:"-"` // 不返回
    Nickname  string    `bson:"nickname" json:"nickname"`
    Avatar    string    `bson:"avatar" json:"avatar"`
    Status    string    `bson:"status" json:"status"` // online/offline
    CreatedAt time.Time `bson:"created_at" json:"created_at"`
    UpdatedAt time.Time `bson:"updated_at" json:"updated_at"`
}
```

### Message

```go
type Message struct {
    ID         string    `bson:"_id,omitempty" json:"message_id"`
    SenderID   string    `bson:"sender_id" json:"sender_id"`
    ReceiverID string    `bson:"receiver_id" json:"receiver_id"`
    Content    string    `bson:"content" json:"content"`
    MsgType    string    `bson:"msg_type" json:"msg_type"` // text/image/file
    Status     string    `bson:"status" json:"status"`       // sent/delivered/read
    ReadAt     *time.Time `bson:"read_at,omitempty" json:"read_at,omitempty"`
    CreatedAt  time.Time `bson:"created_at" json:"created_at"`
}
```

## 第一阶段验收标准

| 检查项 | 要求 |
|--------|------|
| □ 用户注册 | 可创建用户，密码加密存储 |
| □ 用户登录 | 返回 JWT，后续接口可认证 |
| □ 获取用户信息 | 携带 Token 可获取自身信息 |
| □ 更新用户信息 | 可修改昵称等字段 |
| □ REST 发送消息 | 可发送消息并持久化到 MongoDB |
| □ 获取消息列表 | 可按用户分页查询历史消息 |
| □ 标记已读 | 可将消息状态更新为 read |
| □ WebSocket 连接 | 客户端可建立 WebSocket 连接 |
| □ WebSocket 发送消息 | 实时消息可送达在线用户 |
| □ WebSocket 接收消息 | 客户端可收到推送消息 |
| □ 心跳机制 | 连接保持活跃，超时断开 |
| □ 单元测试 | Auth 和 Message Service 有测试 |
| □ 代码规范 | 通过 golangci-lint |
